EXPERIMENT NO. 3
1. Experiment Title
Your First HTML Page
2. Aim
Create HTML documents with a title, headings, paragraphs, and text formatting.
3. Software / Tools Required
VS Code or text editor, web browser
4. Theory
HTML uses elements and tags to structure web content. The head contains metadata and the title; the body contains visible content. h1–h6 represent heading levels; p represents paragraphs; strong and em add semantic emphasis; br creates a line break.
5. Algorithm / Procedure
12.	Create first.html with doctype, html, head, title, and body.
13.	Add the requested h1 and open the page in a browser.
14.	Create headings.html with h1, h2, h3, and a paragraph.
15.	Create text-format.html with two paragraphs, strong, em, and br.
6. Program / Queries / Commands
first.html
<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>My First Page</title></head>
<body><h1>Hello, I am Asha.</h1></body>
</html>

headings.html
<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Headings</title></head>
<body>
  <h1>Welcome</h1>
  <h2>About This Page</h2>
  <h3>Learning HTML</h3>
  <p>This page demonstrates HTML headings and a paragraph.</p>
</body>
</html>

text-format.html
<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Text Formatting</title></head>
<body>
  <p>HTML makes text <strong>important</strong> and meaningful.<br>Here is a new line in the same paragraph.</p>
  <p>We can also <em>emphasize</em> words in a sentence.</p>
</body>
</html>

7. Input
Text content is written directly in the HTML files.
8. Output
Browser tab shows My First Page; the pages display headings, paragraphs, bold/strong emphasis, italic/emphasis, and a line break.
